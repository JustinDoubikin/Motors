# Vector Control

This directory contains Vector Control implementations for motor control.

## Applications
- AC motor control with decoupled torque and flux control
- High-performance drives

## Controller Files
Place your Vector Control implementations (.m, .slx) here.

## Components
- Coordinate transformations
- Flux control loop
- Torque control loop
- Current controllers
- PWM modulation

## Variants
- Rotor flux oriented control
- Stator flux oriented control
- Air gap flux oriented control
