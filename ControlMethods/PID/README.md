# PID Control

This directory contains PID (Proportional-Integral-Derivative) control implementations for motor control.

## Applications
- Speed control
- Position control
- Current control

## Controller Files
Place your PID controller implementations (.m, .slx) here.

## Parameters
- Proportional gain (Kp)
- Integral gain (Ki)
- Derivative gain (Kd)
- Anti-windup methods
- Saturation limits

## Tuning Methods
- Ziegler-Nichols method
- Cohen-Coon method
- Manual tuning
