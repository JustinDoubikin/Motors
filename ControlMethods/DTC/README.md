# Direct Torque Control (DTC)

This directory contains Direct Torque Control implementations for AC motor control.

## Applications
- Induction motor control
- PMSM control

## Controller Files
Place your DTC controller implementations (.m, .slx) here.

## Components
- Flux estimator
- Torque estimator
- Hysteresis comparators
- Switching table
- Voltage vector selection

## Advantages
- Fast torque response
- No coordinate transformations required
- No PWM modulator needed
