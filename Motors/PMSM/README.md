# PMSM Motor Models

This directory contains MATLAB models and simulations for Permanent Magnet Synchronous Motors.

## Motor Types
- Surface-mounted PMSM (SPM)
- Interior PMSM (IPM)

## Model Files
Place your PMSM motor model files (.m, .slx) here.

## Parameters
Common parameters include:
- Stator resistance (Rs)
- d-axis inductance (Ld)
- q-axis inductance (Lq)
- Permanent magnet flux linkage (λm)
- Number of pole pairs (p)
- Motor inertia (J)
- Damping coefficient (b)
