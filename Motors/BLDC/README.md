# BLDC Motor Models

This directory contains MATLAB models and simulations for Brushless DC motors.

## Motor Types
- 3-phase BLDC motors
- Inner/Outer rotor configurations

## Model Files
Place your BLDC motor model files (.m, .slx) here.

## Parameters
Common parameters include:
- Phase resistance (Rs)
- Phase inductance (Ls)
- Back EMF constant (Ke)
- Number of pole pairs (p)
- Motor inertia (J)
- Damping coefficient (b)
