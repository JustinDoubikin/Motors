# Stepper Motor Models

This directory contains MATLAB models and simulations for Stepper motors.

## Motor Types
- Bipolar stepper motors
- Unipolar stepper motors
- Hybrid stepper motors

## Model Files
Place your Stepper motor model files (.m, .slx) here.

## Parameters
Common parameters include:
- Phase resistance (R)
- Phase inductance (L)
- Number of steps per revolution
- Holding torque
- Detent torque
- Motor inertia (J)
