# DC Motor Models

This directory contains MATLAB models and simulations for DC motors.

## Motor Types
- Brushed DC motors
- Permanent magnet DC motors
- Series/Shunt/Compound wound DC motors

## Model Files
Place your DC motor model files (.m, .slx) here.

## Parameters
Common parameters include:
- Armature resistance (Ra)
- Armature inductance (La)
- Back EMF constant (Ke)
- Torque constant (Kt)
- Motor inertia (J)
- Damping coefficient (b)
