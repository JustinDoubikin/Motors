# Induction Motor Models

This directory contains MATLAB models and simulations for Induction motors.

## Motor Types
- 3-phase induction motors
- Squirrel cage motors
- Wound rotor motors

## Model Files
Place your Induction motor model files (.m, .slx) here.

## Parameters
Common parameters include:
- Stator resistance (Rs)
- Rotor resistance (Rr)
- Stator inductance (Ls)
- Rotor inductance (Lr)
- Mutual inductance (Lm)
- Number of pole pairs (p)
- Motor inertia (J)
